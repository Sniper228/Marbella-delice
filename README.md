# Marbella Delice

Site vitrine premium pour la marque de yaourts fruites **Marbella Delice**.

## Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- Framer Motion
- Phosphor Icons

## Demarrage

```bash
cd marbella-delice
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Sections

1. Hero immersive (yaourt SVG, fruits flottants, mesh gradients)
2. A propos (storytelling)
3. Produits (5 saveurs)
4. Fraicheur et qualite (piliers + statistiques animees)
5. Promotions / Instagram
6. Livraison et WhatsApp
7. Temoignages (glassmorphism)
8. Galerie masonry
9. Footer premium

## Personnalisation

- Numero WhatsApp : `src/lib/data.ts` (`WHATSAPP_URL`)
- Produits, stats, temoignages : `src/lib/data.ts`
- Couleurs et tokens : `src/app/globals.css`
